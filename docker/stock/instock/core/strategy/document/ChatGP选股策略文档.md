## 2. 股票池构建（五层过滤体系）

### 2.1 第一层：财务安全过滤（排除地雷股）

| 指标 | 条件 | 说明 |
|------|------|------|
| 资产负债率 | < 60% | 排除高财务杠杆 |
| 每股经营现金流 | > 0 | 确保造血能力 |
| 商誉/净资产 | < 20% | 排除商誉暴雷风险 |
| 流动比率 | ≥ 1.0 | 短期偿债能力 |
| 速动比率 | ≥ 0.8 | 快速偿债能力 |

### 2.2 第二层：盈利能力筛选（选出优质公司）

| 指标 | 条件 | 说明 |
|------|------|------|
| ROE(加权) | ≥ 15% | 股东回报率基准 |
| 毛利率 | ≥ 30% | 产品定价权指标 |
| 净利率 | ≥ 10% | 成本控制能力 |
| ROA | ≥ 5% | 资产使用效率 |
| ROIC | ≥ 10% | 资本回报率(可选) |

> 💡 **优质公司标准**：ROE ≥ 15% 且毛利率 ≥ 30%，说明公司具有定价权和竞争优势

### 2.3 第三层：成长质量筛选（确保可持续增长）

| 指标 | 条件 | 说明 |
|------|------|------|
| 营收3年CAGR | > 10% | 业务规模扩张 |
| 净利润3年CAGR | > 10% | 盈利能力增长 |
| 扣非净利润增长 | > 0% | 主业增长确认 |
| 净利润CAGR > 营收CAGR | 推荐 | 经营杠杆释放 |

> ⚠️ **警惕**：利润增速远超营收增速可能是非经常性收益，需检查扣非利润

### 2.4 第四层：竞争壁垒评估（护城河筛选）

| 维度 | 评估标准 | 权重 |
|------|----------|------|
| 上市年限 | ≥ 5年（市场验证） | 10% |
| 行业地位 | 细分行业 Top3 | 20% |
| 市占率趋势 | 稳定或提升 | 15% |
| 行业周期 | 非强周期 | 10% |
| 护城河类型 | 见下方详细评估 | 45% |

**护城河类型识别：**
| 类型 | 特征 | 典型行业 |
|------|------|----------|
| 品牌效应 | 高毛利率 ≥40%，定价权 | 白酒、奢侈品 |
| 技术壁垒 | 高研发投入，专利护城 | 医药、芯片 |
| 规模效应 | 成本领先，高市占率 | 家电、建材 |
| 网络效应 | 用户规模正反馈 | 互联网平台 |
| 转换成本 | 高客户粘性，低流失 | 软件、金融 |
| 牌照壁垒 | 稀缺准入资质 | 银行、券商 |

### 2.5 第五层：估值约束（买入价格控制）

| 指标 | 条件 | 说明 |
|------|------|------|
| PE(TTM) | 0 < PE ≤ 50 | 排除亏损和泡沫 |
| PE | ≤ 5年历史中位数 | 相对估值合理 |
| PEG | ≤ 1.5 | 成长性价比 |
| PB(MRQ) | ≤ 10 | 资产估值上限 |
| 股息率 | > 0（推荐） | 分红意识加分 |

👉 **最终股票池规模**：10–20 只

3. 技术指标体系（只用于择时）

原则：
趋势 + 均值回归 + 情绪确认
所有指标统一在 日线 → 周线 → 月线降噪

4. 买入策略（分三类）
4.1 第一类：趋势内回调买入（核心）

适用场景：优质公司，长期趋势未破

使用指标

MA20 / MA60（日线 & 周线）

RSI(14)

成交量 MA20

买入条件（全部满足）
1️⃣ 周线 MA20 > MA60（长期趋势向上）
2️⃣ 日线价格回调至 MA20 ±2%
3️⃣ RSI(14) ∈ [40, 55]
4️⃣ 回调缩量，反弹放量

动作
→ 买入 30% 目标仓位

4.2 第二类：超跌修复买入（情绪错杀）

适用：市场恐慌但基本面未变

使用指标

RSI(14)

Bollinger Bands(20,2)

成交量

买入条件
1️⃣ RSI < 30
2️⃣ 股价跌破布林下轨后 3 日内收回
3️⃣ 放量长下影 / 阳线
4️⃣ 无基本面利空

动作
→ 买入 20%–30% 仓位

4.3 第三类：突破确认买入（谨慎）

只用于“核心资产”

使用指标

MA60

近 60 日高点

成交量

买入条件
1️⃣ 横盘 ≥ 8 周
2️⃣ 放量突破区间高点
3️⃣ 成交量 ≥ 过去 20 日均量 ×1.5

动作
→ 小仓位试探（≤20%）

5. 卖出策略（比买入更重要）
5.1 技术性减仓（估值未崩，但涨过头）
使用指标

RSI

Bollinger Bands

成交量

条件（任一满足）
RSI > 75 且连续 3 日
价格触及布林上轨并放量滞涨

动作
→ 减仓 20%–30%

5.2 趋势破坏卖出（必须执行）
使用指标

MA60（周线）

成交量

条件（全部满足）
1️⃣ 周线跌破 MA60
2️⃣ 连续 2 周无法收回
3️⃣ 下跌放量

动作
→ 清仓

5.3 基本面卖出（优先级最高）
- 财务质量恶化
- 核心竞争力下降
- 行业长期逻辑被证伪


👉 不看技术，直接卖

6. 仓位管理（量化友好）
单只股票最大仓位：10%
核心股票最大仓位：15%
行业集中度上限：30%

分批模型
首次买入：30%
二次买入：30%
三次买入：20%
预留机动：20%

7. 风控规则（系统级）
7.1 回撤控制（组合层面）
组合最大回撤 > 20%
→ 停止加仓
→ 降低整体仓位

7.2 黑天鹅保护
- 个股单日跌幅 > 8%
- 且无明确利好解释
→ 临时冻结交易

8. 周 / 月执行逻辑（适合代码）
周度（轻量）
- 更新技术指标
- 判断是否触发买卖条件
- 不调整基本面

月度（核心）
- 更新财务 & 行业数据
- 调整股票池
- 决定是否淘汰个股

9. 策略核心总结（一句话）

基本面决定方向，
技术指标决定时机，
风控决定你能走多远。
